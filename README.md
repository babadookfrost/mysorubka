# 🔪 МЯСОРУБКА

**2D top-down survival shooter, где время подчиняется тебе**

*Двигаешься — время идёт. Остановился — мир замирает.*

## 🎮 Что это

«Мясорубка» — это быстрый roguelike-шутер с видом сверху. Ты — последний, кто остался на арене, а вокруг орда монстров: от мелких мясников до боссов, которым мало одного уровня ярости.

Главная фишка — **время**. Пока ты бежишь — враги, пули и мир живут полной жизнью. Стоишь на месте — всё замирает. Научись этим пользоваться: перезаряжайся в заморозке, прицеливайся не спеша, планируй следующий рывок.

Каждые 10 убитых — новая волна. На 10-й волне каждого уровня приходит **босс**. Победил — получил новое оружие и перешёл на следующий уровень. Умер — начинай сначала, но счёт и рекорды остаются.

## ✨ Фишки

| | |
|---|---|
| 🔫 **8 видов оружия** | Пистолет, дробовик, автомат, пулемёт, лук, гранатомёт, огнемёт и рельсотрон — каждое со своим характером, звуком и трассерами |
| 🌳 **Дерево навыков** | 5 веток: Кровь, Тень, Время, Щит, Хаос — 25 перков и **имбовая форма** в конце каждой |
| 🧠 **Умные враги** | Обходят стены (flow-field), не толпятся, стрелки целятся с упреждением и уворачиваются от твоих пуль |
| 👹 **Боссы с фазами** | На половине HP босс впадает в ярость: ускоряется, спавнит миньонов и атакует чаще |
| ⚖️ **3 сложности** | Лёгкая, средняя и адская — свои множители, свои рекорды и свои награды |
| 🔥 **Элитные враги** | На адской сложности монстры становятся элитными: огненные, ядовитые, быстрые, берсерки и щитовые — светятся и дают больше XP |
| 🎨 **Скины за победу** | Победи босса на средней или адской — открой «Золотого чемпиона» или «Адского демона» с огненным следом |
| 🎵 **Живой звук** | Синтезированный саундтрек, который нарастает при приближении босса, и звук на каждый выстрел |
| 💥 **Сочные эффекты** | Числа урона, трассеры пуль, hit-stop при крите, вспышки, виньетки и партиклы на каждом шагу |

## ⚔️ Имбовые формы

Прокачай ветку до конца — и станешь машиной смерти:

- **КРОВАВЫЙ ДЕМОН** — урон ×3.25, 100% вампиризм, кровавая аура
- **ПРИЗРАК** — 80% уклонение, +30% скорости, теневые клоны
- **ХРОНОМАСТЕР** — замедляет врагов на 85%
- **ЖЕЛЕЗНЫЙ ГОЛЕМ** — 75 HP, −80% входящего урона, шипы
- **ФЕНИКС** — 5 снарядов за раз, цепная молния и **возрождение после смерти**

## 🚀 Как запустить

### Веб-версия (проще всего)
Просто открой `index.html` в любом современном браузере. Всё, больше ничего не нужно — никаких сборок и зависимостей. Работает на компьютере, планшете и телефоне.

### Android (исходники)
Открой проект в Android Studio и запусти на эмуляторе или устройстве:

```bash
# сгенерируй .env с ключом Gemini, если хочешь ИИ-фичи:
echo "GEMINI_API_KEY=your_key_here" > .env
```

## 🛠️ Технологии

- **Веб:** чистый JavaScript + Canvas — ноль зависимостей, один файл
- **Android:** Kotlin + Jetpack Compose, Room (база рекордов), ViewModel
- **Звук:** Web Audio API — вся музыка и эффекты синтезируются на лету, без единого аудиофайла
- **Сохранения:** localStorage (рекорды, статистика, скины, настройки)
